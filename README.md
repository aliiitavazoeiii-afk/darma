# DARMA Store

Custom ecommerce storefront for DARMA.

## Product direction

- Visual language: COS-like minimalism
- Homepage hero: ARKET-inspired full-bleed video/image treatment
- Faster path from landing page to products than either reference
- Mobile-first, conversion-first, SEO-first
- Persian / RTL storefront

## Initial stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- PostgreSQL-ready backend architecture
- Server-rendered product/category pages
- Product / Offer / Breadcrumb structured-data ready

## Domain

`darma.biya2film.top`

## Status

Phase 0 initialized. Product photography, final visual identity, checkout provider and shipping rules will be integrated in later phases.
